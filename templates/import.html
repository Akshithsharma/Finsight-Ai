Format your CSV

These column names are recognized (case-insensitive):

  • Date — YYYY-MM-DD
  • Description — merchant or transaction details
  • Amount — numeric value
  • Type — optional: income/expense or credit/debit
  • Category — optional; otherwise suggested by rules
